# 🤖 AI Chatbot

A simple AI chatbot built with **Python** and **Ollama**.
The chatbot takes user questions from the terminal and generates AI-powered responses using a locally running Llama model.

## ✨ Features

* 🤖 AI-powered conversations
* 🐍 Built with Python
* 🧠 Uses Llama 3.2 through Ollama
* 💻 Runs directly in the terminal
* 🔒 Runs locally using Ollama
* 👋 Type `bye` to exit the chatbot

## 🛠️ Technologies Used

* Python
* Requests
* Ollama
* Llama 3.2

## 📋 Requirements

Before running the project, make sure you have:

* Python installed
* Ollama installed
* Llama 3.2 model downloaded

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/prachisonare065-creator/AI-Chatbot.git
```

### 2. Open the project

```bash
cd AI-Chatbot
```

### 3. Create and activate virtual environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 4. Install Requests

```bash
pip install requests
```

### 5. Start Ollama

Make sure Ollama is running and the `llama3.2` model is available.

### 6. Run the chatbot

```bash
python chatbot.py
```
